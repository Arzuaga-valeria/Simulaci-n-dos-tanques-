# Simulación: dos tanques acoplados con recirculación

Simulación interactiva de un sistema de dos ecuaciones diferenciales ordinarias.

## Archivo
- `index.html`: contiene la simulación completa; no requiere dependencias ni compilación.

## Publicar con GitHub Pages
1. Crea un repositorio nuevo en GitHub.
2. Sube `index.html` a la raíz del repositorio.
3. Abre **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/(root)`, y guarda.
6. Espera a que aparezca el enlace del sitio en la sección **Pages**.
